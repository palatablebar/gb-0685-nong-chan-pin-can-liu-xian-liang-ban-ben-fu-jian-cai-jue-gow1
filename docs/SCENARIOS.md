# 检测场景

12个苹果样本分4批，每个样本初检P01为<0.01mg/kg，采样日标准限量0.005，因此不确定。次日同样本同方法复检0.004且LOD0.001。S001复检声明扩展不确定度0.002，区间[0.002,0.006]跨越限量，判UNCERTAIN并暂缓待补；S002复检声明0.0005，区间[0.0035,0.0045]不越限，判PASS；其余复检未声明不确定度，按点值判PASS并替代原报告。每样本P02为30ug/kg，超过0.02mg/kg，仍FAIL；S001的P02声明不确定度5ug/kg，下界0.025仍超限。最终24项目，11PASS、12FAIL、1UNCERTAIN，23项准予发布、1项暂缓待补，四批均FAIL。脏批额外含缺LOD、同版冲突、错列、空行与重复表头。
